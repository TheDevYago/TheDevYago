## Sobre Mim

Sou um desenvolvedor Front-End apaixonado por criar interfaces responsivas, dinâmicas e intuitivas. Busco sempre aliar o design de UI/UX com boas práticas de código para construir experiências incríveis para os usuários.

- **Acadêmico:** Graduando em Engenharia de Software pela Universidade Católica do Salvador (UCSAL).
- **Foco Técnico:** Atuação forte no ecossistema Web, construindo aplicações complexas com **Angular** e **TypeScript**, e garantindo integrações sólidas com o Back-End.
- **Off-topic:** Fora das telas, estou sempre nadando.
