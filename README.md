### 👨‍💻 Sobre Mim

Sou um desenvolvedor Front-End apaixonado por criar interfaces responsivas, dinâmicas e intuitivas. Busco sempre aliar o design de UI/UX com boas práticas de código para construir experiências incríveis para os usuários.

* 🎓 Graduando em **Engenharia de Software** pela Universidade Católica do Salvador (UCSAL).
* 💻 Tenho atuado fortemente no ecossistema Web, com grande experiência na construção de aplicações complexas utilizando **Angular** e **TypeScript**, garantindo integrações eficientes com serviços de Back-End.
* 🏊‍♂️ **Fora das telas:** praticamente sempre nadando.
